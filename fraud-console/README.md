# Fraud review console
npm install && npm run dev
Mock data is ON by default (toggle in the queue or Demo lab). Untick it to use the real API (default http://localhost:8000, override with VITE_API_URL in .env). The backend needs CORS enabled for http://localhost:5173.
Demo logins: analyst@fraudlens.dev / demo123, admin@fraudlens.dev / admin123 (sees Demo lab), viewer@fraudlens.dev / view123 (read-only).
